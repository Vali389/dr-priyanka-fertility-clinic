# Five-page website refresh

## What will change
- Keep the existing blush, wine, serif-led visual identity while making the presentation fresher and more professional.
- Replace the current one-page navigation with five real pages: Home, About, Services, Blog, and Contact.
- Give each page a strong image-led opening, useful page-specific sections, subtle gradients, and scroll fade animations.
- Keep Dr. Priyanka’s real portrait prominent and reuse the existing clinic, fertility, consultation, and pregnancy imagery appropriately.

## Page structure
- **Home:** concise introduction, key specialties, credibility, patient journey, selected stories, and appointment call-to-action.
- **About:** biography, qualifications, philosophy, experience highlights, and clinic approach.
- **Services:** fertility, pregnancy, and women’s health services with conditions treated and care pathways.
- **Blog:** polished editorial listing with useful women’s health and fertility topics.
- **Contact:** appointment options, clinic details, hours, directions, and a professional enquiry form.

## Technical details
- Move shared navigation and footer into reusable components so every page is consistent.
- Add unique search and social metadata to every page.
- Use bundled project imagery for backgrounds; no autoplay video will be added because the available still imagery already supports a calmer, faster medical experience.
- Verify navigation, page rendering, animations, and mobile/desktop layouts in the live preview.
